찬예웨스트 쇼핑몰 데모

실행: index.html 파일을 크롬/엣지에서 열면 됩니다.
img 폴더의 이미지 파일이 사이트에 사용됩니다.

현재 구현: 반응형 홈/계절 섹션, 상품 카드, 검색, 장바구니, 쿠폰 자동 적용,
새벽배송 추가비, 데모 회원가입/로그인(localStorage), 마네킹 코디 조합,
키/몸무게/얼굴형 기반 스타일 제안.

중요: 실제 운영에 필요한 보안 로그인, 데이터베이스, 재고/주문 관리,
회원 누적 구매액 기반 등급·포인트 자동 적립, 실제 카드/간편결제(PG),
배송사/새벽배송 연동은 백엔드 및 외부 서비스 계약이 추가로 필요합니다.
현재 회원가입/결제/추천은 프론트엔드 시연용입니다.
